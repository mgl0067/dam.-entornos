# Cierre. nuestro proyecto completo
En el README, explica cómo desarrollarías una pequeña aplicación o juego.

- 01. Problema, plataforma y lenguaje.

Un juego de plataformas en 2D con estilo pixel-art/8-bits, donde hay que ir superando fases para poder pasar a la siguiente e ir consiguiendo habilidades nuevas. Con un botón se puede cambiar el plano y/o perspectiva que tiene el personaje principal para poder ver el escenario desde distintos ángulos. 
Tengo pensado que el juego sea para ordenador o navegador web, en lenguaje java o html respectivamente.

- 02. Algoritmo o ejemplo de paradigma que usarías.

Para cambiar la perspectiva del juego se usaría una variable para almacenar en que perspectiva se encuentra actualmente el personaje:
int perspectiva = 1;

- 03. Cómo llega el código a ejecutarse.

En caso de hacer el juego únicamente en ordenador se ejecuta directamente con un archivo .java desde el propio ordenador donde se quiere jugar. En caso de hacerlo en html el juego se ejecuta directamente desde el navegador del dispositivo.

- 04. Commit, push y comprobación.

Desde github desktop hacemos un commit del readme.md para guardar el archivo y un push para subirlo a nuestro repositorio, posteriormente comprobamos que se vea en la web.
